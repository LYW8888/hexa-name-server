# 星际未来感＋东方美学

用户明确选择“星际未来感＋东方美学感”后，本轮重新设计客户页与管理端。页面已经落入 React 代码，以下截图来自本地实际构建与合成输入，不是概念图。生产站点尚未部署本轮代码。

## 实施目标

以深空、星轨、微光与银色字形呈现未来感，以中文衬线字体、香槟金细节、留白和山水曲线保留东方气质。重新组织首屏入口、表单、名字提案和报告咨询区，同时保持已有业务流程、报告权限与账号隔离。

## 结构与交互

- 首页采用完整的深空展示区域、原创SVG“名”字与轨道图形；三个快捷入口直接切换实际表单，并反映当前选中的场景。
- 预产期、已出生、改名保持独立校验。切换首页入口会保留原有场景资料；改名仍先分析现名，再明确生成推荐。生成期间快捷切换被禁用；控制器同样拒绝分析期间切换。
- 起名工作区采用说明与表单并列的电脑布局；手机采用单列，将场景入口放在装饰图形之前。偏好和排盘设置仍默认收起。
- 名字提案重新安排字形、拼音、寓意与操作层级，使用候选末字作为装饰底纹；底纹不重复加入读屏内容。手机操作区域至少44px。
- 报告咨询采用内容说明与联系面板并列的电脑布局，手机自动改为上下排列。微信LCEX511、QQ19437771、主动同意、申请编号与人工交付链路保留。
- 登录页、后台侧栏、工作总览、岗位表格及报告预览采用同一视觉语言；超级管理员初始化、Argon2id、动态码和权限边界沿用现有实现。

星轨是装饰，不对应实时天体数据或计算结果；公开客户端依然只获得名字、读音和简短寓意。完整算法数据只由经营者在独立后台读取和导出。

## 实现与访问

新增视觉由本地SVG与CSS绘制，没有新增图片下载、WebGL或动画库依赖。字形轻微浮动和星光变化由CSS执行；系统设置减少动态效果时关闭。SVG仅作装饰并从读屏内容隐藏，页面交互保持真实文字与原生表单。

暗色输入框、日期控件、焦点、错误提示、收藏弹窗和手机导航统一处理；保留Escape关闭和焦点返回。手机输入字号16px。实际验证范围包含1440px电脑、390px手机及320px窄屏，不将Chromium验证表述为所有浏览器认证。

## 验证与发布

完整回归共 **309项通过**：Python算法与HTTP服务168项、Node规则25项、后台身份与权限27项、客户账号26项、客户端浏览器52项、后台浏览器6项、客户账号浏览器5项。前端生产构建、站点HTTP自检及差异检查通过。

新增两个浏览器场景覆盖桌面与手机的首页三个入口、选择同步、场景资料保留和真实生成请求。已有用例继续验证未来预产期、准确出生时间、改名顺序、数量选择、收藏比较、报告申请、人工交付、管理员首次改密及角色隔离。

本轮没有新增依赖或数据库迁移。生产部署需拉取提交，执行`npm ci --prefix frontend`与`npm run build --prefix frontend`，完整发布同一次构建，并重启提供页面的现有服务。此前尚未部署的后台、报告进程、初始化与域名仍按各自部署说明配置，不能只更新前端就视为后台已开通。
