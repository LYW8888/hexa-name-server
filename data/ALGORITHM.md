# 计算规则和资料边界

规则版本：`traditional-reference-v1` / `naming-match-v2`（喜用与真太阳时扩展见 [MINGLI_RULES.md](MINGLI_RULES.md)）。

## 从时间到计算

1. 按 `bazi.py` 已声明的历法口径计算四柱：立春换年、十二节换月、当地民用时间23:00换日。新生儿预产期、已出生和改名分别选择计算依据，混填两种日期会拒绝请求；未来预产期允许通过。可选经度与真太阳时修正见扩展说明。
2. `tradition.chart_details` 按十天干、十二地支的固定属性计阴阳，合计8项；按 `lunar_python 1.4.8` 的 `LunarUtil.ZHI_HIDE_GAN` 表列地支藏干。藏干次数与表面五行次数分开，均不作为强弱权重。十神按相对日干的五行关系与阴阳同异计算；月支本气取藏干表第一项。
3. `tradition.cast` 使用常见梅花易数类年月日时起卦口径：农历年支子1至亥12，月取月序，日取日序，时支子1至亥12。年数+月数+日数除8取上卦，加时数除8取下卦，总数除6取动爻。余0分别作8或6。先天卦序乾兑离震巽坎艮坤；爻从下往上，翻转一爻得到变卦。动爻所在卦为用，另一卦为体。
4. 起卦农历年以春节分界，农历日期按民用00:00换日，闰月按同月序；和四柱的立春、23:00口径分别标明。所有候选共用本次时间起卦，不按名字随机分配卦象。

手算锚点：2024-02-10 12:00，上海时间，甲辰农历正月初一，年支数5、月1、日1、午时7。上卦7艮，下卦14余6坎，动爻14余2；本卦蒙，变卦剥，体艮土、用坎水。对应四柱甲辰、丙寅、甲辰、庚午；表面阴0阳8，不能据此断吉凶。

这是一套声明口径的传统文化计算，不是《周易》直接规定的唯一算法。阴阳、生克、月令、扶抑与八卦意象原则已完成固定录文的出处对照，见 [CLASSICAL_SOURCES.md](CLASSICAL_SOURCES.md)；历法权威认证仍与原文核对分别记录。现已实现限定口径的月令格局、扶抑旺衰与喜用参考，见扩展说明；调候、大运、康熙笔画数理尚未实现，不把“缺什么补什么”当作结论。

## 从规则到候选排序

先按名的字数和避用字硬筛选，不更换长度补数量。`elementPreference=auto` 将体卦五行作为可选的字形意象偏好，**不当作八字喜用神**；`none` 关闭这一项，或由用户明确选择五行。

汉字五行没有唯一公认归类。当前只采用容易说明的直接部首规则：木→木，水/氵/氺→水，火/灬→火，土→土，金/钅/釒→金。其他部首明确“未归类”，不使用旧演示笔画或人为补齐。按日主与字形分组显示生克关系，仅解释，不用于推导吉凶。

| 匹配分项 | 满分 | 规则 |
| --- | ---: | --- |
| 字形意象 | 30 | 同目标五行满分、生目标半分，其他及未归类0分；按名的全部字数平均。关闭则整项不计。 |
| 风格 | 20 | 至少一个所选风格在候选标签中；没有选择则不计。 |
| 心意用字 | 20 | 喜欢字和主动启用的父母姓氏取并集，按命中比例；没有偏好则不计。避用字仍优先。 |
| 寓意关键词 | 20 | 显式关键词及标签匹配，支持少量否定前缀；无输入则不计。不是复杂语义理解。 |
| 读音字典对照 | 20 | 名的预设读音均列入普通话单字字典；不检查完整姓名谐音或方言。 |
| 姓名重复 | 10 | 姓与名没有相同汉字。 |
| 性别偏好 | 10 | 已知性别匹配候选标签；未知不计。标签只是整理倾向。 |

字形分项保留两位小数、其他分项取整后合计，除以本次启用分项满分并归一到100；返回每项分子、分母和理由。不使用预设基础分。分数仅在同一次条件内比较，不是运势分、专业审美评价或不同输入间可比较的绝对评分。相同条件可出现并列。变更生辰不保证每次改变五行偏好或名字；不同时间可能得到同体卦、同元素。

候选库65条只是有限候选集，没有声称穷尽全部可用名字。寓意为本项目撰写的现代字义组合说明，独立于四柱分析规则的古籍引用。标为 `verified` 必须有版本、条目、许可、复核人和日期；本次未新增此标记。

## 部首资料来源

`character-catalog.json` 收录102个覆盖候选及常见姓氏的部首事实，提取自 `cnradical 0.1.0` 的部首映射。项目：https://github.com/wangchuan2008888/cn-radical ，作者元数据：Wang Chuan；上游声明 Apache Software License / Apache License。许可文本随附 [LICENSE-cnradical](LICENSE-cnradical)。仅保存 JSON 事实快照，不引入该库的 pickle 加载器或运行依赖。上游字典的原始出处、异体字及逐字人工复核尚未完成，因此不宣称官方字表或商业核验词典。

运行 `python3 -m unittest discover -s tests` 可复查干支阴阳、十神关系、藏干、起卦手算锚点、动爻、场景时间隔离、现名分析和偏好排序；历法跨库/天文样本验证见根目录README。测试通过不等于专业命理或机构认证。

真太阳时可替换日/时柱与起卦钟面，但不改变年/月柱的实际节气时刻。新增 `yongshen` 模式使用独立扶抑参考，不能将体卦元素当作八字喜用。喜用分项用神1、喜神0.75，其余0；需要复核或中和时停用这一分项。

## 改名的现名分析

`name_review.py` 用完整现用姓名生成结构、字典读音与多音选项、重复字、逐字部首分组、相对日主关系，以及同一实际出生四柱的分析报告。寓意仅在现有候选字库收录该名时返回，并附原始资料类别；未收录不补造释义或五行。现名报告不计算吉凶分。

界面先呈现现名报告，经用户继续后设置改名偏好；现名或出生事实变化会使已确认报告失效。推荐时按当前出生事实重算现名报告，排除原全名，给出保留/新用汉字及字数变化。改名不会改变出生四柱，偏好匹配也不表示改名前后的运势差值。
