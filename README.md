# 序名 · 现代东方命名

响应式中文姓名方案原型，面向新生儿起名与成人改名场景。界面采用现代东方视觉语言，当前版本以可解释的传统文化参考和前端交互为主，核心历法与资料服务预留为可替换模块。

## 本地运行

仓库没有外部依赖，直接启动静态服务器：

```bash
python3 server.py
```

访问 `http://localhost:4173`。服务器同时提供 `/api/health`、`/api/catalog` 和 `/api/analyze` 接口。

## 当前能力

- PC、平板和手机响应式界面
- 新生儿起名 / 成人改名入口
- 分步信息表单、输入校验和移动端适配
- 五行参考摘要与候选名字卡片
- 候选名字收藏（浏览器本地存储）
- 基础键盘焦点、减少动态效果支持

当前候选数据为演示用本地数据，不应视为完整八字、历法或经典资料库。接入正式服务时，应把历法计算、笔画数据、经典出处和姓名评分拆成独立且可测试的规则模块，并保留来源信息。

## 规则层说明

`engine.js` 将出生信息分析、候选资料、长度筛选、风格偏好和评分拆开，方便以后替换为正式的农历/四柱、真太阳时、汉字笔画和出处数据服务。当前结果明确标注为演示规则；项目不会把未核验资料写成经典引文，也不会把运势表述为确定预测。

## 手机端安装

在支持 PWA 的移动浏览器中打开页面后，可使用“添加到主屏幕”。首次访问会缓存本地页面、样式和规则脚本；正式部署时建议通过 HTTPS 提供服务。

收藏数据只保存在当前浏览器的 `localStorage` 中，页面底部提供“清除本地收藏”入口。出生日期、出生地和父母姓氏不会被发送到网络服务；接入后端时应继续遵循最小采集和可删除原则。

## 算法数据库阶段

算法数据库已开始建立，位于 `data/`。当前先落地可审计的数据结构和一组演示字库，字段包含拼音、声调、五行候选、字义、风格、康熙笔画、来源和核验状态。正式接入前还需要补齐权威历法、四柱、笔画和经典出处数据，并为每个版本建立复核记录。


## API 示例

```bash
curl -s http://localhost:4173/api/health
curl -s -X POST http://localhost:4173/api/analyze -H "Content-Type: application/json" -d '{"surname":"林","date":"2024-04-16","time":"08:30","place":"杭州","parents":"沈","length":2,"styles":["classical"]}'
```

提交表单时，浏览器会优先调用同源 `/api/analyze`，取得本地 SQLite 规则层的分析结果；接口不可用时自动回退到浏览器内置演示规则，保证静态预览仍可使用。

## 起名场景逻辑

- **按预产期起名**：允许未来日期，默认使用 `12:00` 作为参考时间，并在结果中标记“预产期参考”。
- **已出生起名**：使用出生日期和准确时间，未来日期会被拒绝，并在结果中标记“已出生准确时间”。
- **性别**：支持男、女、未知；未知不会施加性别倾向，男/女会参与候选排序。

预产期和实际出生信息可以同时保存。预产期用于保留原始计划，实际出生日期和准确时间一旦填写，会成为主要计算依据；预产期未来日期不会触发出生日期错误。表单错误会显示在页面内，不再使用浏览器原生弹窗。
